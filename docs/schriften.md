# Eingebundene Schriften

Für Deckblatt und Seitenbeschriftung im Export sind diese Schriften in das Programm eingebunden. Sie liegen unter `crates/core/fonts/` und stehen unter der SIL Open Font License 1.1 (frei nutzbar, auch eingebunden und kommerziell).

| Schrift | Verwendung |
| --- | --- |
| Poppins (Regular, Medium) | Themen Klar und Meer |
| Lora Italic | Thema Leinen |
| Barlow Condensed (Medium, Bold) | Thema Nacht |
| Caveat und Rubik Mono One | Thema Kraft (Handschrift, Stempel) |
| IBM Plex Mono Medium | Thema Galerie |

Quellen: Google Fonts (github.com/google/fonts). Die Lizenztexte der Schriften gehören bei einer Weitergabe des Programms mit dazu.
