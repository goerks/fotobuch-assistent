# Pitch und Demo vor jedem Testlauf

Vor jedem Testlauf entsteht eine Seite mit Pitch, Demo (Screenshots der echten App auf einem nachgebauten Fotoordner) und Prüfliste. Die Seite ist eine einzelne HTML-Datei, die man im Browser öffnet.

- [testlauf-1.html](testlauf-1.html): erster Testlauf, Demo mit New-York-Reise und Orten
- [testlauf-2.html](testlauf-2.html): Buchansicht mit Seitenlayouts, Begründungen, grösseren Bildern

Der Demo-Ordner entsteht mit `python tools/demo_fotos.py <zielordner>`. Es sind synthetische Bilder, keine echten Fotos.
