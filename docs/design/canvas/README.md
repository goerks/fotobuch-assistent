# Design-Vorschläge (Quelle)

Diese Dateien sind die Quelltexte der Design-Boards, die vor jedem Schritt gezeigt wurden (ein Board je Schritt, vorher links, Erklärung in der Mitte, nachher rechts). Sie liegen im Claude-Design-Artifact «Fotobuch: Ablauf verbessern» (Link steht in `docs/uebergabe.md`).

- `Main.dc.html` = Schritt 1 (Umfang), `Schritt2` bis `Schritt6` = weitere Schritte, `Ideen.dc.html` = Fensterrahmen-Ideen.
- `canvas.json` ordnet die Boards auf der Leinwand an.
- Die Bilder in den Boards sind in Claude hochgeladen (`/_blob/...`) und fehlen hier. Ohne sie sind die Boards nur als Text und Layout lesbar. Die fertigen Vorher/Nachher-Bilder je Schritt liegen unter `docs/galerie/schritte/`.
- `../rahmen-auswahl.html` ist die interaktive Rahmen-Auswahl (eine einzelne HTML-Seite, im Browser lauffähig).
