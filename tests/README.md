# Tests

Hier liegen automatische Tests und Berichte der Machbarkeits-Etappe.

- Es werden **keine Fotos** eingecheckt (siehe `.gitignore`).
- Testbilder für automatische Tests werden im Test selbst erzeugt (synthetische Bilder).
- Berichte aus Läufen mit echten Fotos enthalten nur Zahlen, Gruppenlisten und Dateinamen, keine Bilder.
